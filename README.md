# tumbleweed

Tumbleweed is a physics engine made for the 3D Physics Engine Tutorial series.

https://www.youtube.com/@TheHurtDev

## Running the Demo

1. Install Rust and Cargo: https://doc.rust-lang.org/cargo/getting-started/installation.html
1. Run the demo:

```sh
cargo run --release --example demo
```

## Branching Strategy

A separate release branch is created for each episode in the series. This lets you check
out the appropriate branch to see that episode's concepts demonstrated in practice.

The `main` branch always reflects the latest episode's changes. In general, branches for
previous episodes will not be updated except to fix major issues or bugs.
